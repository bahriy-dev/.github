# Getting help

- **Questions about using a project:** open a [discussion or issue](https://github.com/bahriy-dev) in that repository and include the version and a minimal example.
- **Bugs:** use the *Bug report* issue template.
- **Feature ideas:** use the *Feature request* issue template.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Never post them publicly.
- **Anything else:** [bahriyilmaz.dev](https://bahriyilmaz.dev) or [LinkedIn](https://www.linkedin.com/in/bahriyilmaz/).
