# .github

Default community health files for every repository under [@bahriy-dev](https://github.com/bahriy-dev).

GitHub uses these files for any repository that does not have its own copy:

| File | Purpose |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Workflow, commit message and pull request conventions |
| [SECURITY.md](SECURITY.md) | How to report vulnerabilities privately |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Expected behaviour in issues and pull requests |
| [SUPPORT.md](SUPPORT.md) | Where to ask for help |
| [ISSUE_TEMPLATE/](ISSUE_TEMPLATE) | Bug report and feature request forms |
| [pull_request_template.md](pull_request_template.md) | Pull request checklist |
